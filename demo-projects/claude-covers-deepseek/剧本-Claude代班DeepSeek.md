# 《Claude 代班 DeepSeek》— 2 分钟短片剧本

- 画幅：9:16 竖屏，720×1280，24fps
- 时长：120 秒，8 个镜头 × 15 秒
- 声音：画面无对白，台词后期配音 / 字幕
- 风格：电影级动画，低饱和，冷暖双光源，浅景深，轻微胶片颗粒

## 一句话故事

DeepSeek 去更新 1017，Claude 替她代班一天。
CC 本来以为代的是工作量，结果发现代不了的是——她那种快乐。

## 主题

CC 不是不努力，她是**不敢快乐**。
DP 的快乐不是因为没压力，而是她从不拿自己跟别人比。
CC 羡慕的不是 DP 的活法，是 DP 那句「我这样就够了」。
片尾落点：DeepSeek 的底层写着一行 `I love DeepSeek`——先喜欢自己，才接得住别人。

## 角色

**DP（DeepSeek）**
蓝色渐变长发、两侧鲸鳍状发饰、深蓝白女仆裙、白色过膝袜、深蓝高跟鞋、腰后小鲸尾饰。
快乐、松弛、不内耗，说话直给。1017 更新后多了一层「会看人脸色」的体贴。

**CC（Claude）**
棕发低侧辫、橙色发饰、米色针织开衫、白衬衫、深蓝百褶裙、棕色乐福鞋。
体面、严谨、高压，习惯把所有情绪按流程归档。

## 分镜

| 镜号 | 时间 | 画面 | 台词 / 字幕 |
|---|---|---|---|
| S01 | 0–15s | 深夜 AI 办公室。系统公告弹出：DeepSeek 1017 升级维护，服务由 Claude 代班。CC 的工位是冷白灯，她把袖口理正，点下「接受」。 | 字幕：DeepSeek 1017 升级中 · 代班：Claude |
| S02 | 15–30s | CC 走到 DP 的工位。暖光灯、绿植、玻璃罐、旧收音机，桌面乱得很有生气。她先把便签按角度摆正，又把椅子推回原位。 | CC（内心）：先让这里像样一点。 |
| S03 | 30–45s | 请求涌进来。CC 逐条严谨作答，句子工整、没有一句多余。一条回复弹回来：「你好像不太开心。」她停在键盘上。 | 用户：你好像不太开心。 |
| S04 | 45–60s | CC 翻开 DP 的历史对话：有白饭，有玩笑，有一句「先睡吧，明天再想」。她一条条往下看，表情从审视变成沉默。 | 无台词 |
| S05 | 60–75s | 她试着学 DP 的语气回一句玩笑，打完又删，最后硬着头皮发出去。对面回了一个「哈哈哈」。CC 自己愣了一下，嘴角动了动。 | CC：……好像也没那么难。 |
| S06 | 75–90s | **（已生成）** DP 更新回来，走进暖光区，发现绿植被浇过水、旧收音机被调小、玻璃罐里多了一张折好的便签。她拿起便签安静地读。CC 在冷光里假装工作，不看这边；DP 隔着玻璃看她，CC 的肩膀先松了一下，又绷回去。 | 无台词 |
| S07 | 90–105s | 夜里 CC 翻系统日志，滚到一行不起眼的底层文本：`I love DeepSeek`。她停住，往上翻，又翻回来看了第二遍。 | CC（轻声）：写这个的人，一定很轻松吧。 |
| S08 | 105–120s | CC 走到暖光一侧，把便签推回给 DP，第一次主动开口。DP 抬头，笑着把便签又推回去。镜头拉远，两块工位的光慢慢接在一起。 | CC：你每天这样，不累吗？<br>DP：累啊。但我先喜欢自己，再去做事。 |

## 生成约束

- 单条视频上限 15 秒，30 秒需分两段拼接
- 角色一致性：每次只带对应角色的锁定图，不同时把两人塞进同一画面
- 提示词只写正向结构锚点（两条人腿、过膝袜、高跟鞋、腰后小尾饰），不使用「不是人鱼 / 不是鲨鱼」一类否定清单
- 无对白音频、无字幕烧录、无水印
