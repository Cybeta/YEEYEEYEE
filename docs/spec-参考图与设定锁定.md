# 参考图与设定锁定

当前版本：`0.1.5.1`，桌面项目 `<Version>` 已同步，依据 2026-10-10 当前源码。以下区分已实现的检查、已验证的媒体交互与尚未完成的效果及资产验收。

## 目标与流程

角色、道具和场景跨镜复用，通过实体、变体、版本引用与设定图减少漂移。人物一致性尚未实际验收通过，历史项目资产尚未实际补齐，不能把机制存在或自检无错误写成效果验收通过。

```text
明确资产需求 → 绑定设定及版本 → 补齐设定图 → 生成并采用分镜首帧 → 分镜视频 → 成品视频
```

## 资产需求与版本硬检查

分镜对角色、场景、道具分别记录“未知 / 无需求 / 必要”。未知或非法值阻断生成；必要类别必须有引用，无需求类别不能仍保留该类引用。整批一键任务在开始前检查目标分镜及资产补图所影响分镜的需求，不能先执行部分任务再靠临时确认绕过。

设定按实体、变体、附件保存。引用可以跟随最新或锁定版本；锁定版本读取该版本内容。失效引用、指定版本缺失、所引用版本没有可用图片、版本决策待确认均阻断。需重新绑定、补图或明确处理版本选择。本轮资产补图失败会阻断依赖镜头，即使还留有旧图。

## 参考图选择与容量

- 顺序固定为角色 → 道具 → 场景，同类内按引用顺序。
- 每条引用占一个槽位，从解析出的引用内容中取第一张可用图片；多张设定图不会自动全部作为参考。
- 上限取用户设置、池子已声明张数和工作流最大单组图片容量的最小值。池子未声明张数不按零处理；用户设置为零是真实约束。
- 分镜必要参考不能取消勾选、过滤或裁剪。超限或来源不支持参考时阻断，需调整上限或更换来源；不能改成无参考生成。
- 最终请求必须包含全部必要路径，路径不得为空、数量不得超限。底层选择器仍有筛选/裁剪逻辑，但不能据此宣称分镜提交允许省略必要参考。

## 生成输入快照与过期判定

图像批次在发起时保存实际 `Request`（提示词、参数、参考路径等）及 `SourceFingerprints`。分镜每张候选调用 provider 前再次检查当前资产需求、最终参考路径、容量和来源能力，并比较当前引用指纹与批次快照；不同则失败并要求重新发起生成。重做仍经过最终请求检查，不能凭旧请求跳过必要路径校验。

采用候选图时复制该批次的生成依据，不用采用时的最新设定覆盖。引用指纹包含描述、布局、附件引用、子引用及版本标签；无引用也记录基线。它不是文件字节哈希，也不代表所有输入参数都经过通用不可变快照比较，不能宣称同路径文件被替换一定能检出。

有记录依据的产物与当前引用不一致时提示过期；锁定版本不会因为最新变体改变而自动过期。旧产物或手放素材没有依据时，不应把“没有过期提示”理解为有效。确认资产需求不能补记旧图当时使用的版本，必须按当前引用重新生成并采用首帧。

## 视频首帧检查

视频使用节点上最后一张可用、已采用的图片附件作为首帧，候选批次不算。必要参考的指纹必须存在且匹配，采用首帧依据过期时阻断；提交首帧路径还必须与当前采用首帧一致，变化后需重新打开生成窗口。有引用却没有采用首帧的分镜禁止降级为文生视频。

单图视频接口只接收分镜首帧：角色、道具、场景资产先参与首帧生成，再让这一镜动起来。不能直接把设定图当作分镜首帧；多参考视频能力由接口和工作流决定。

## ComfyUI 多图规则

同组输入顺序填充，独立输出管线按输出节点分组；容量使用最大单组槽位数。素材给不满时未使用槽位保持原值，提交前检查这些服务器文件仍存在。保留工作流槽位原值不等于允许丢掉项目必要参考。已连接输入不覆盖，无法确认槽位语义时保守提示，不自动猜测。

## 媒体查看

画布产物视频单击原位播放，图片/视频双击打开应用内大窗。视频缩略框须完整位于可见区；首帧阶段延迟单击播放，双击取消待播放动作，播放中的双击通过页面消息打开大窗。引用预览入口另走引用画廊，音频使用系统播放器。

视频首帧封面由 FFmpeg 从视频本身解码，不使用设定图冒充；失败保留播放入口。播放默认静音，WebView 按需创建，保持单活动播放器；大窗关闭、画廊切换或控件离开视觉树时释放相应播放器。

## 验收边界与后续标准

最新实际结果：Agent 340 项、Core 32 项通过，solution Release 增量构建 0 警告、0 错误。前轮真实鼠标已验证图片、静止视频及原位播放中的视频双击打开应用内大窗，关闭后回到首帧；不同编码的完整回归仍需单独验证。

全库 ComfyUI 兼容性、人物跨镜一致性及旧项目补资产仍未验收。历史项目需求、引用、图片及首帧依据尚未实际补齐；自检为只读报告，不自动补图，也不会修复历史产物依据。

后续实际验收需确认：未知需求及无效引用确实阻断；必要参考缺失、取消、超限和请求漏带确实阻断；引用变化后的请求及旧首帧确实阻断；补图失败不使用旧图继续；真实多镜生成的人物、服装、道具和场景表现一致。
