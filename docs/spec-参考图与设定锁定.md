# 参考图与设定锁定

## 目标

角色、道具和场景会跨镜复用。将它们保存为设定并绑定参考图，可以减少同一对象在不同分镜中发生漂移。

流程：

```text
设定图 → 分镜图 → 分镜视频 → 成品视频
```

## 当前能力

- 设定按实体、变体和附件保存。
- 分镜通过实体和变体引用设定。
- 设定图变化后，相关分镜会标记为过期。
- 出图时按“角色 → 道具 → 场景”的顺序选择参考图。
- 每个变体默认取第一张图。
- 用户可以在生成前取消某些参考图。
- 上限取用户设置、池子能力和工作流槽位数的最小值。
- ComfyUI 支持单图、多图和服务器声明的文件槽位。
- 视频接口当前按自身能力限制参考图数量，不能带上的图片会明确提示。

## ComfyUI 多图规则

同一组输入按顺序填充。一个文件包含多条独立输出管线时，按输出节点分组后分别填充，避免把图片全部写入错误的管线。

给不满时，未使用的槽位保持原值。生成前会检查这些原值是否仍存在于目标服务器，避免提交后才因示例文件缺失失败。

## 设计边界

- 参考图用于提高一致性，不承诺像素级复刻。
- 图生图中底图已经占用主要输入位，不自动混入其他设定图。
- 视频是否支持多参考图由接口能力决定。
- 无法确认槽位语义时保持原值并提示用户，不自动猜测。

## 验收标准

- 被引用但没有设定图的实体会出现在自检结果中。
- 参考图顺序稳定，超出上限时显示被省略的内容。
- ComfyUI 已连接的输入不会被覆盖。
- 缺失素材在提交前被指出。
