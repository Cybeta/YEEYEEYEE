# 出图开奖与判档

## 开奖

出图完成后可以直接查看缩略图，也可以使用开奖模式：候选图先以卡背显示，逐张揭晓后再选择要收进分镜的图片。

开奖只改变展示方式，不改变生成结果和保存规则。

## 判档

判档使用支持图片输入的视觉模型，根据本次实际发送的提示词和负面提示词对图片进行独立评分，并换算为档位。

- 判的是绝对质量，不是同批次排名。
- 没有视觉模型时可以配置后再判，或跳过本次判档。
- 跳过不等于低分，不会生成虚假的档位。
- 命中负面提示词的结果会单独标记。
- Desktop 可按产品流程对被标记图片重新生成，并受重试次数限制。
- Web 只负责展示判档结果和裂纹标记，不自动重出；是否重新生成由用户自行决定。
- 判档、开奖和裂纹标记都不会替用户自动采用或删除候选文件。
