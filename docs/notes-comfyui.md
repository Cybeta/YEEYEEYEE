# ComfyUI 接入说明

## 使用流程

在设置页输入 ComfyUI 首页地址并测试连接。应用会读取工作流目录、节点定义和当前文件清单，然后把工作流登记为站点。

导入过程分为四步：

1. 读取网页编辑器格式的工作流。
2. 按 ComfyUI 前端规则转换为 API Prompt JSON。
3. 使用 `/object_info` 识别输入类型、固定选项和文件槽位。
4. 在提交前检查缺失输入、缺失文件和无效选项。

转换失败或无法确认时会保留原始工作流，并在界面报告原因。

## 参数绑定

生成时只修改明确识别的输入：

- 正向和负向提示词。
- 宽高、比例和时长。
- `seed`、`noise_seed`、`random_seed`、`随机种子` 等明确种子输入。
- 首帧、图片、视频和音频文件槽位。

规则：

- 已连接的输入保持原连接。
- 固定随机种子节点不参与普通种子绑定。
- 未识别的输入不猜测、不强写。
- 比例优先使用服务器声明的完整选项。
- 时长根据工作流实际入口写入秒数或帧数。

## 参考素材

支持三类常见入口：

- `LoadImage` 等单文件节点。
- 一个输入包含多个文件名的清单节点。
- 服务器声明为文件选择的多个槽位，例如 `图片1` 到 `图片9`。

空槽位是否可用由服务器节点定义决定，不由作者示例文件决定。给出的素材按槽位顺序写入，未提供的槽位保持原值，并在提交前检查原值是否仍存在。

图片、视频和音频槽位分别记录。文件名必须是服务器可见的文件名，不支持把本机路径直接写入工作流。

## 导入检查

导入检查会标记：

- 转换过程中丢失的必需输入。
- 工作流中被静音或绕过的节点。
- 原稿本身断开的连接。
- 服务器缺少的素材、模型或依赖。
- 当前工具无法确认的节点。

“无法确认”不等于“工作流不可用”。应用会保守提示，并在提交前再次校验。

## 常见限制

- 不同节点包的输入名称和语义不统一。
- 某些提示词保存在复杂模板或分镜结构中，无法安全替换时会保持原样。
- 参考图能提高一致性，但不保证生成内容完全跟随参考片。
- 视频多参考图能力由工作流和服务端共同决定。
- 工作流依赖的模型和素材必须存在于目标 ComfyUI 实例。

## 检查重点

如果导入后参数显示为“未识别”，优先检查：

1. `/object_info` 是否包含对应节点。
2. 输入是否为字面量而不是已有连线。
3. 固定选项值是否来自服务器当前清单。
4. 引用的模型或素材是否已上传到目标实例。
