# ComfyUI 接入说明

当前版本：`0.1.5.1`，桌面项目 `<Version>` 已同步。以下依据 2026-10-10 当前源码，描述实现及限制；全库 ComfyUI 兼容性仍未验收。本次执行本地打包及包验证，不操作 git，不做外部发布。

## 使用流程

在设置页输入 ComfyUI 首页地址并测试连接。应用读取工作流目录、节点定义和当前文件清单，将工作流登记为站点。

1. API Prompt 格式直接读取；网页编辑器格式交给桌面注入的官方前端导出器。
2. `NativeWebView` 加载目标 ComfyUI 实例的官方页面，通过 `app.loadGraphData()` 加载原稿，检查图身份和动态节点稳定性，再读取 `app.graphToPrompt().output`。
3. 使用 `/object_info` 识别输入类型、固定选项和图片、视频、音频文件槽位。
4. 导入与提交前检查缺失输入、文件、模型、依赖及无效选项。单份失败记录原因，不能把失败工作流当作可用站点。

## 官方前端转换

Windows 下默认两个 FIFO worker 动态领取任务，共享一个进程级 `CoreWebView2Environment`，每个 worker 独占自己的页面与会话。共享环境不等于共用页面。可用内存低于 4 GiB，或进程工作集超过 1.5 GiB 且可用内存低于 8 GiB 时，降为单 worker；页面初始化串行并错峰。

导出器核对 request ID、worker ID、session、原稿 SHA-256；脚本核验节点注册和加载后的节点身份，等待动态输入稳定，要求连续两次官方输出一致且非空。导出页面禁止提交生成队列，转换本身不执行生图。初始化预算四分钟，初始化后导出预算两分钟；失败、超时或取消销毁页面，拒绝迟到消息污染后续任务。

没有官方前端宿主的调用方会明确失败，不回退 Playwright。共享 WebView2 环境创建失败也不退回每页独立环境。旧 JSON 转换器和学习规则仍在仓库中，但官方导出结果不走旧规则重转换。Reroute、旁路、动态下拉和子图的实际兼容性由目标实例官方前端、节点包及资源决定。

## 参数绑定

生成时只修改明确识别的输入，包括正负提示词、宽高/比例、种子及媒体文件槽位。支持 `seed`、`noise_seed`、`random_seed`、`随机种子` 等明确种子输入。

- 已连接输入保持原连接，固定随机种子节点不参与普通种子绑定。
- 未识别输入不猜测、不强写；比例优先使用服务器声明的完整选项。
- 当前桌面 ComfyUI 视频时长策略沿用工作流，不发送桌面时长值；不能因底层存在时长识别能力就宣称该入口可改秒数或帧数。

## 参考素材与硬检查

常见入口包括 `LoadImage` 等单文件节点、包含多个文件名的清单节点，以及服务器声明的多个文件槽位（如 `图片1` 到 `图片9`）。同组按顺序填充；独立输出管线按输出节点分组。工作流图片容量按最大单组槽位数计算，不使用所有管线槽位总和。

空槽是否可用由服务器节点定义决定。素材给不满时，未使用槽位保留原值，提交前检查原值在服务器上是否存在。这不允许省略项目中的必要参考：分镜必须明确角色、场景、道具需求，必要引用缺图、失效、缺指定版本、待处理版本决策、取消勾选、最终请求漏带、来源不支持参考或超限，都会阻断生成，不能裁剪或降级为无参考生成。

参考上限取用户设置、已声明的池子上限和工作流单组容量的最小值。池子未声明张数不等于零容量；用户设置为零则是真实限制。图片、视频和音频槽位分别记录，写入的文件名必须是服务器可见的文件名，不能直接把本机路径当作服务器文件名。

图像批次保存实际请求及引用指纹，分镜每张候选调用 provider 前再次检查最终路径、上限、来源能力及当前指纹。采用图片继承该批次生成时的依据。视频提交核对当前采用首帧及必要参考依据；候选图不算已采用，旧图不能通过确认需求补记依据。详见[参考图与设定锁定](spec-参考图与设定锁定.md)。

## 检查重点与限制

- 转换失败需检查官方前端是否就绪、节点类型是否注册、图身份是否改变、动态输入是否稳定以及资源是否可用。
- 参数“未识别”需检查 `/object_info`、输入是否已有连线、固定选项是否来自当前清单、素材及模型是否在目标实例。
- 无法确认的槽位应保守提示；不等于所有工作流不可用，也不等于可以绕过硬检查提交。
- 某些提示词位于复杂模板或分镜结构中，无法安全替换时保持原样。
- 单图视频使用已采用的分镜首帧，角色、场景、道具先用于生成首帧；多参考视频能力由接口和工作流决定。
- 人物跨镜一致性尚未实际验收通过，历史项目资产尚未实际补齐。导入和请求校验不能证明生成效果一致。

## 证据与验证范围

代码入口为 `ComfyUiLibrary.FetchOneAsync`、`SelectWorkerCount`、`Reconvert`，桌面宿主为 `ComfyUiNativeWebViewExporter` / `SharedWebView2Environment`，官方脚本为 `ComfyUi.Export.js`；资产校验见 `GenerationAudit.CheckImageSubmission` 与 `CheckVideoAssets`。

最新实际结果：Agent 340 项、Core 32 项通过，solution Release 增量构建 0 警告、0 错误。前轮真实鼠标已验证图片、静止视频和原位播放视频双击应用内大窗，关闭回到首帧。上述测试与交互结果不代表全库 ComfyUI 兼容性验收；既有四样本记录三个成功、一个因图身份改变失败，不能推广为全库通过。人物一致性及旧项目补资产仍未验收。详细本地探针记录不属于公开使用说明，不复制实例地址或原始工作流数据。

仓库已清理 12,937 个文件，共 3.16 GiB；删除记录见根目录 `Dream清理删除清单-20261010.csv`。旧转换器等源码没有明确死码证据时不盲删。
