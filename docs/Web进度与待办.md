## 部署条件与限制

- 源码开发默认地址为 `http://localhost:5000`（`appsettings.json`）；Docker Compose 默认为 `http://localhost:8080`。
- 要在页面创建/打开项目，配置 `YEEYEEYEE__WebProjectsDirectory` 为服务账号可写的项目父目录；已配置项目画布模式时也可使用该项目父目录。独立 scene 模式未配父目录时不提供创建/打开能力。
- Docker 卷需同时覆盖任务、账号、聊天库、素材、配置及项目目录。仅构建镜像不能证明重启后持久化或密钥可解密；Linux 本机密钥文件与配置应由同一服务账号保存并安全备份。
- 新模型/媒体密钥保存必须取得实际加密结果；加密不可用返回错误。换机器或账号后旧密钥可能不可读，需重新填写。
- Web 媒体设置保存的是桌面共享配置；Web 任务执行地址仍取服务启动配置。修改页面配置不能保证已启动执行器立即切换地址。
- Web 可导入 ComfyUI API Prompt；UI 工作流需先在目标官方前端导出 API，当前 Web 服务没有桌面官方前端宿主，不伪转换。
- 聊天附件、资源媒体的类型、签名和大小受限；技能调用不支持任意文件、完整实体参考或任意参数。
