## 已发布 0.1.5.1

以下为既有已发布 `0.1.5.1` 的历史记录（2026-10-10），桌面项目 `<Version>` 已为 `0.1.5.1`。本次更新四份文档并执行本地发布打包与包验证，不操作 git，不做外部发布；应用内更新链路仍需单独验收。

- 明确官方 ComfyUI 转换路径：Windows 默认双 FIFO worker 共享一个 WebView2 环境，各自拥有独立官方前端页面；内存条件触发时降为单 worker。通过 `loadGraphData` 与 `graphToPrompt().output` 导出，核对请求、worker、会话、原稿 SHA-256、图身份及稳定输出。失败、超时或取消销毁页面，没有宿主不回退 Playwright，官方结果不套旧学习转换规则。
- 明确角色、场景、道具资产需求三态。未知需求、需求与引用冲突、失效引用、版本或图片缺失、版本决策待确认阻断；必要参考不能取消、过滤、裁剪或降级为无参考生成。整批先检查需求，本轮补图失败阻断依赖镜头。
- 明确生成输入快照范围：图像批次保存实际请求和引用指纹，每张分镜候选提交前复核最终参考路径及指纹，采用时保留生成依据。指纹不是图片文件内容哈希，也不等于全参数不可变检查。视频核对当前采用首帧、必要参考依据及过期状态，候选图不算采用首帧，确认需求不能补记旧图依据。
- 明确画布产物视频单击原位播放、图片/视频双击应用内大窗。视频预览须完整可见，默认静音，按需创建 WebView 并保持单活动播放器；播放中的双击由页面消息转到大窗，关闭或切换释放播放器。引用入口另走画廊，音频仍走系统播放器。
- 明确视频封面由 FFmpeg 提取视频真实首帧，失败保留播放入口，不用设定图代替。Windows 构建/发布配置要求随附 FFmpeg 可执行文件、许可证及说明，缺失会阻断构建；本次发布包检查覆盖 FFmpeg 可执行文件、许可证及说明。
- 更新当前测试与构建结果，删除可取消必要参考及超限省略等过时口径；保留使用流程、参数绑定、版本引用、多图槽位和历史说明。桌面 ComfyUI 视频时长沿用工作流，不宣称桌面时长值已发送。
